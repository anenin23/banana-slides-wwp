## 概述

Banana Slides 以客户端-服务器架构运行，包含 Flask 后端和 React 前端。本指南介绍远程部署、工作进程生成和访问控制的配置选项。

## 主机与端口配置

后端默认绑定到 `0.0.0.0`（所有网络接口），支持远程访问。

```env
BACKEND_PORT=5000
FRONTEND_PORT=3000
```

从源码运行且未设置 `BACKEND_PORT` 时，端口会根据项目目录名自动计算，使多个 worktree 获得唯一端口。

<Tip>
  Docker 容器内部固定使用 5000 端口。`BACKEND_PORT` 控制宿主机端口映射。
</Tip>

## 远程访问控制

### 访问口令

使用访问口令保护实例。所有 `/api/` 端点将要求在 `X-Access-Code` 请求头中提供口令：

```env
ACCESS_CODE=your-secret-code
```

留空则不启用口令验证。

### CORS 跨域配置

控制哪些来源可以访问 API：

```env
# 允许所有来源
CORS_ORIGINS=*

# 限制为特定来源（逗号分隔）
CORS_ORIGINS=https://example.com,https://app.example.com
```

## 工作进程生成选项

Banana Slides 使用 `ThreadPoolExecutor` 生成后台工作线程，用于并发执行 AI 生成任务。两个线程池处理不同的工作负载：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `MAX_DESCRIPTION_WORKERS` | `5` | 生成页面描述和大纲的最大并发线程数 |
| `MAX_IMAGE_WORKERS` | `8` | 图片生成任务的最大并发线程数 |

```env
MAX_DESCRIPTION_WORKERS=5
MAX_IMAGE_WORKERS=8
```

<Warning>
  工作线程数设置过高可能超出 AI 服务商的速率限制或导致内存不足。请根据服务商套餐和服务器资源进行调整。
</Warning>

这些值也可以通过网页设置页面在运行时修改，无需重启服务器。

## 子进程生成

后端会为特定任务生成外部子进程：

### LibreOffice（PPTX 转 PDF）

PPT 翻新功能使用 LibreOffice 无头模式将上传的 PPTX 文件转换为 PDF：

```bash
libreoffice --headless --convert-to pdf <input.pptx>
```

- 超时时间：每次转换 120 秒
- 需要单独安装 LibreOffice（默认未包含）

Docker 部署时安装方法：

```bash
docker exec -it banana-slides-backend bash -c \
  "apt-get update && apt-get install -y libreoffice-impress && rm -rf /var/lib/apt/lists/*"
```

<Note>
  建议在上传前先在本地将 PPTX 转换为 PDF，因为服务器端 LibreOffice 转换可能因缺少字体而产生不准确的结果。
</Note>

## Docker 部署

### 使用预构建镜像

```bash
docker compose -f docker-compose.prod.yml up -d
```

### 从源码构建

```bash
docker compose up -d
```

### 容器配置

`docker-compose.yml` 生成两个服务：

| 服务 | 内部端口 | 宿主机端口变量 | 健康检查 |
|------|----------|---------------|----------|
| `backend` | 5000 | `BACKEND_PORT` | 每 30 秒 `GET /health` |
| `frontend` | 80 | `FRONTEND_PORT` | — |

### 健康监控

后端提供健康检查端点用于远程监控：

```bash
curl http://your-server:5000/health
# 响应: {"status": "ok", "message": "Banana Slides API is running"}
```

Docker 每 30 秒自动执行健康检查，超时 10 秒，最多重试 3 次。

## 环境变量与超时设置

远程运行时配置 AI 服务商的连接超时：

```env
# Gemini 超时时间（秒）
GENAI_TIMEOUT=300.0
GENAI_MAX_RETRIES=2

# OpenAI 兼容服务商超时时间（秒）
OPENAI_TIMEOUT=300.0
OPENAI_MAX_RETRIES=2
```

## 生产环境检查清单

远程部署前，请确认：

- 设置 `FLASK_ENV=production` 以禁用调试模式和自动重载
- 设置强密码 `SECRET_KEY`
- 如果实例可公开访问，配置 `ACCESS_CODE`
- 将 `CORS_ORIGINS` 限制为前端域名
- 根据服务器容量调整 `MAX_DESCRIPTION_WORKERS` 和 `MAX_IMAGE_WORKERS`
- 为 AI 服务商设置适当的超时时间
